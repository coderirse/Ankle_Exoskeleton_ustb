# ESP32-S3 足底双开关 — 接线说明

> 硬件：正点原子 DNESP32S3 开发板（ATK-MWS3S 模组）
> 固件：`src/esp32_switch/`（ESP-IDF 工程）
> 协议：0x41~0x44，状态变化即发 + ~50ms 心跳，与 STM32 版完全一致，ROS 侧无需改动

## 一、引脚分配总表

| 功能 | GPIO | 方向 | 说明 |
|---|---|---|---|
| 后脚跟开关 | **IO4** | 上拉输入 | 开关一端接 IO4，另一端接 **GND** |
| 前脚掌开关 | **IO5** | 上拉输入 | 开关一端接 IO5，另一端接 **GND** |
| 外接 LED1（脚跟指示） | **IO6** | 输出，高电平点亮 | IO6 → 限流电阻 → LED正极，LED负极 → GND |
| 外接 LED2（脚掌指示） | **IO7** | 输出，高电平点亮 | IO7 → 限流电阻 → LED正极，LED负极 → GND |
| 板载红色 LED | IO1 | 输出，低电平点亮 | 板载，无需接线 |
| 数据输出 | 原生 USB | — | Type-C 线直连电脑，免接线 |

## 二、开关接线（脚跟 + 脚掌）

开关为**常开微动/薄膜开关**，按下导通：

```
IO4 ──┬── 脚跟开关 ── GND
IO5 ──┬── 脚掌开关 ── GND
```

- 使用开发板内部上拉，**无需外部电阻**
- GND 可接排针上任意 GND 脚
- 逻辑：按下 = 开关闭合 = 读到低电平 = 有效

## 三、外接 LED 接线（2 个）

```
IO6 ── 1kΩ 电阻 ── LED1 正极(长脚)
LED1 负极(短脚) ── GND

IO7 ── 1kΩ 电阻 ── LED2 正极(长脚)
LED2 负极(短脚) ── GND
```

- 限流电阻 1kΩ（3.3V 驱动，电流约 1~2mA；想要更亮可用 330Ω~510Ω）
- **必须串电阻**，直推会烧 GPIO
- 指示逻辑：脚跟踩下 LED1 亮、脚掌踩下 LED2 亮（与 STM32 版一致）

## 四、板载 LED 指示含义（无需接线）

| 状态 | 板载红色 LED |
|---|---|
| 0x42 双开关闭合（站立/全掌） | **常亮** |
| 0x41 / 0x43 单开关闭合 | **快闪（5Hz）** |
| 0x44 双开关都松开（摆动相） | **慢闪（1Hz）** |

## 五、数据通道

- 用烧录的那根 **Type-C 线**即可：固件通过 USB Serial/JTAG 把状态字节直接发给电脑
- 电脑侧端口为 `/dev/ttyACM*`（如同时插着 IMU，注意区分端口号）
- USB CDC 无波特率概念，`serial_sendCommand_node` 的 9600 设置不影响通信
- **注意**：上电时 ESP32 的启动日志也会从这个口输出（一堆 ASCII 文本），ROS 节点已有 0x41~0x45 过滤，不受影响

## 六、与 STM32 版的位置对应

原 STM32 采集板的 PB12（脚跟）、PB1（脚掌）分别对应 ESP32 的 IO4、IO5；PA1/PA2 指示 LED 对应 IO6/IO7（注意电平极性相反：STM32 版低电平点亮，ESP32 外接 LED 为高电平点亮）。

## 七、烧录

```bash
cd ~/git_/Ankle_Exoskeleton_ustb/src/esp32_switch
source ~/esp/esp-idf/export.sh
idf.py build flash -p /dev/ttyACM0
```

（板子若插在其他端口，用 `ls /dev/ttyACM* /dev/ttyUSB*` 确认后替换端口号）
