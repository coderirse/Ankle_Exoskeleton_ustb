# 足底双开关采集模块 — 接线与通信协议

## 1. 硬件接线

### STM32F103C8T6 最小系统板

```
                    STM32F103C8T6
                  ┌─────────────────┐
  后脚跟开关 ─────┤ PB12        PA9  ├──── USART1_TX → USB转串口 RX
                  │                 │
  前脚掌开关 ─────┤ PB1         PA10 ├──── USART1_RX ← USB转串口 TX
                  │                 │
  LED1(后跟指示)──┤ PA1         GND  ├──── USB转串口 GND
                  │                 │
  LED2(前掌指示)──┤ PA2          5V  ├──── USB转串口 VCC (可选)
                  └─────────────────┘
```

### 开关接线

每个微动开关有 3 个引脚（常开 NO / 公共 COM / 常闭 NC），接法：

```
  STM32 PB12 ───── COM
                    NO ──── GND

  STM32 PB1  ───── COM
                    NO ──── GND
```

- 使用 **常开 (NO)** 端：按下时导通到 GND，STM32 读到低电平
- STM32 内部上拉，松开时为高电平
- 不需要外部上拉电阻

### LED 接线（可选，调试用）

```
  STM32 PA1 ──→ 1kΩ ──→ LED(+) ──→ LED(−) ──→ GND   (LED1 = 后脚跟)
  STM32 PA2 ──→ 1kΩ ──→ LED(+) ──→ LED(−) ──→ GND   (LED2 = 前脚掌)
```

### 串口接线

```
  STM32 PA9 (TX)  ────→  USB转串口 RX
  STM32 PA10 (RX) ────→  USB转串口 TX
  STM32 GND       ────→  USB转串口 GND
```

## 2. 串口参数

| 参数     | 值          |
|----------|-------------|
| 波特率   | 9600        |
| 数据位   | 8           |
| 停止位   | 1           |
| 校验位   | 无          |
| 流控     | 无          |

## 3. 通信协议

### 发送方向：STM32 → 上位机

**仅在步态相位发生变化时**，发送 1 个字节，无帧头帧尾。

| 后脚跟开关 | 前脚掌开关 | 发送字节 | 助记 | 步态相位       |
|:----------:|:----------:|:--------:|:----:|----------------|
| 按下 (ON)  | 松开 (OFF) | `0x41`   | `A`  | 脚跟着地       |
| 按下 (ON)  | 按下 (ON)  | `0x42`   | `B`  | 全掌接触       |
| 松开 (OFF) | 按下 (ON)  | `0x43`   | `C`  | 脚跟离地       |
| 松开 (OFF) | 松开 (OFF) | `0x44`   | `D`  | 脚尖离地       |

### 正常步态时序

```
时间 ──────────────────────────────────────────────────────→

后脚跟  ‾‾‾‾‾‾‾╲________________________________________╱‾‾‾
                 ╲                                      ╱
前脚掌  ‾‾‾‾‾‾‾‾‾‾‾‾╲______________________________╱‾‾‾‾‾‾

发送    ...  0x41      0x42         0x43         0x44  ...
              ↑          ↑            ↑            ↑
           脚跟着地   全掌接触     脚跟离地     脚尖离地
           (支撑开始) (预张紧)    (扭矩驱动)   (摆动相)
```

### 接收方向：上位机 → STM32

当前版本 STM32 不接收上位机数据，仅单向发送。

## 4. ROS2 上位机对接

修改 `serial_sendCommand_node.cpp` 中的串口配置：

```cpp
ser.setPort("/dev/ttyUSB0");    // STM32 对应的 USB 转串口设备号
ser.setBaudrate(9600);          // 匹配 STM32 串口波特率
```

协议完全兼容，无需修改指令解析逻辑。

## 5. 调试方法

1. 用 USB 转串口连接电脑，打开串口助手（9600 8N1）
2. 手动按下/松开开关，观察串口助手是否收到 `41 42 43 44`
3. LED1 跟随后脚跟状态（按下亮），LED2 跟随前脚掌状态
4. 如果指令顺序不对，检查两个开关的接线是否接反
