## 1. 今日进展

### 脚底开关：从完全不通到稳定接收
- **端口发现**：脚底开关 USB-TTL 在 `/dev/ttyUSB2`（之前一直在 `ttyACM0` 上跟 IMU 较劲）
- **固件修复**：HSI→PLL 48MHz 稳定时钟，1ms轮询+3ms消抖，开机发初始状态
- **接线确认**：PA9→USB-TTL RX, PA10→USB-TTL TX, GND→GND
- **LED 引脚**：PA1(后跟), PA2(前掌), 低电平亮
- **开关引脚**：PB12(后跟), PB1(前掌), 内部上拉, 按下=低

### 全系统联调
- **脚底开关 → ROS2 → 助力 → 电机** 全链路打通
- 0x43 后跟离地触发 DRIVE，电机输出助力扭矩
- 0x44 归位需要编码器数据

## 3. 固件编译烧录

```bash
# 编译
arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -O2 -nostartfiles -nostdlib \
    -T /tmp/link.ld -Wl,--build-id=none fw.c -o fw.elf
arm-none-eabi-objcopy -O binary fw.elf fw.bin

# 烧录
sudo st-flash --hot-plug write fw.bin 0x08000000

# 复位（NRST 没接，用 OpenOCD）
sudo openocd -c "source [find interface/stlink.cfg]; source [find target/stm32f1x.cfg]; init; reset run; shutdown"

# 拔掉 ST-LINK USB 线再插上也可以
```

## 5. 踩开关顺序

```
1. 踩后跟          → 0x41  记录编码器位置
2. 后跟不放 + 踩前掌 → 0x42  计算峰值扭矩
3. 松后跟(前掌还踩着) → 0x43  助力扭矩! 电机输出
4. 松前掌          → 0x44  摆动归位(需要编码器)
```
