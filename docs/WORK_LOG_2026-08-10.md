- 引脚：IO4=脚跟开关、IO5=脚掌开关（上拉输入，开关接地）；IO6/IO7=外接双 LED（高电平点亮，串 1kΩ）；IO1=板载红色 LED（低电平点亮）
- 板载 LED 组合指示：0x42 常亮 / 0x41、0x43 快闪 / 0x44 慢闪

- 坑：IDF 默认 FreeRTOS tick=100Hz，`vTaskDelay(1ms)` 失效 → sdkconfig.defaults 设 `CONFIG_FREERTOS_HZ=1000`

## 3. EMI 状态爆发问题（重要发现）

- 现象：脚部动作时开关状态出现 ~0.5s 的四状态循环扫掠爆发（44→43→42→41→44…），真实稳定状态完全正确
- 定位：长杜邦线 + 内部弱上拉（~45kΩ）= 天线效应；不是触点抖动（抖动不会四状态有序扫掠）
- 演进：8ms 消抖（无效）→ 40ms 消抖（仍无效，爆发内假状态可持续 40ms+）→ **步态转移图过滤**（只接受物理合法转移 44→41→42→43→44 及相邻回退）+ 500ms 超时重同步防锁死 + 44→42 整脚平放 80ms 持续确认
- 待验证：真实步态下的表现
- **硬件建议（根治）**：IO4/IO5 加 1~4.7kΩ 外部上拉 + 各 100nF 对地电容，开关线双绞；做完可把消抖降回 8ms
