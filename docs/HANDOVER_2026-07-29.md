## 2. 系统架构

```
┌─────────────────┐      UART      ┌──────────────────────────┐
│ 足底开关 STM32  │───────────────▶│ serial_sendCommand_node  │
└─────────────────┘   /dev/ankle_switch   │   (C++)                  │
                                          │   发布 /command_topic    │
                                          └──────────┬───────────────┘
                                                     │
                     ┌─────────────────┐            │
                     │  力传感器        │◀───────────┘
                     │  D056+DYMH113   │     /Force
                     └────────┬────────┘
                              │ Modbus RTU
                     ┌────────▼────────┐
                     │serial_ForceSensor│
                     │    _node (C++)   │
                     └────────┬────────┘
                              │
                     ┌────────▼────────┐      /angle
                     │ serial_encoder   │◀────────────┐
                     │    _node (C++)   │             │
                     └────────┬────────┘             │
                              │                       │
                              ▼                       │
                     ┌─────────────────┐              │
                     │can_ankleControl │              │
                     │    _node (C++)   │              │
                     │                 │              │
                     │  状态机 + PID   │              │
                     │  预紧 + 助力曲线 │              │
                     └────────┬────────┘              │
                              │ CANopen SDO 0x60FF     │
                              ▼                       │
                     ┌─────────────────┐              │
                     │  CANalyst-II    │──────────────┘
                     │  libcontrolcan  │   编码器 (Modbus)
                     └────────┬────────┘
                              │ CAN bus
                              ▼
                     ┌─────────────────┐
                     │   电机驱动器     │
                     │   node 0x53     │
                     └─────────────────┘
```

**参与的 ROS2 节点（缺一不可）：**

| 节点 | 话题/作用 | 硬件 |
|------|----------|------|
| `serial_ForceSensor_node` | 发布 `/Force` | 力传感器 `/dev/ankle_force` |
| `serial_encoder_node` | 发布 `/angle` | 编码器 `/dev/ankle_encoder` |
| `serial_sendCommand_node` | 发布 `/command_topic` + 时序话题 | 足底开关 `/dev/ankle_switch` |
| `can_ankleControl_node` | 订阅上述话题，控制电机 | CANalyst-II `/dev/ankle_can` |

可选：
- `fdilink_ahrs` 包提供 `/imu`、`/system_speed`，用于坡度补偿（当前未启用）

## 3. 硬件连接与端口映射

所有串口已通过 udev 规则固定为符号链接，避免 `/dev/ttyUSB*` 序号变化。

| 符号链接 | 当前指向 | 设备 | 波特率/协议 |
|---------|---------|------|-----------|
| `/dev/ankle_encoder` | `/dev/ttyUSB0` | 编码器 | Modbus RTU 9600 |
| `/dev/ankle_switch` | `/dev/ttyUSB1` | 足底开关 | UART 9600 |
| `/dev/ankle_force` | `/dev/ttyUSB2` | 力传感器 | Modbus RTU 19200 |
| `/dev/ankle_can` | `bus/usb/001/008` | CANalyst-II | USB-CAN (04d8:0053) |

**udev 规则文件：** `scripts/99-ankle.rules`

**安装命令（若符号链接丢失需重跑）：**
```bash
cd ~/git_/Ankle_Exoskeleton_ustb
sudo cp scripts/99-ankle.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
ls -la /dev/ankle_*
```

> 注意：三个 CH340 串口设备没有唯一序列号，规则基于 USB 拓扑（拓展坞端口）。若更换 USB 口或拓展坞，需重新采集 `ENV{ID_PATH_TAG}` 并更新 `scripts/99-ankle.rules`。

## 6. 已验证内容

### ✅ CAN 通信
- `libcontrolcan.so` 原生 API 成功打开 CANalyst-II
- `VCI_OpenDevice/InitCAN/StartCAN` 返回 STATUS_OK
- NMT + CANopen SDO 使能电机成功
- 电机按 `0x60FF` 速度指令响应

### ✅ 传感器
- 力传感器 `/Force` 20Hz 稳定发布（当前读数约 1.3~8.0，随电机张力变化）
- 编码器 `/angle` 正常发布（当前约 1.56°）
- 足底开关 `/command_topic` 正确发布 0x41~0x44

### ✅ 状态机
手动按足底开关按钮，控制节点状态正确切换：
- `0x41` → `TORQUE_MODE`：存储支撑相起始电机角度
- `0x42` → `PRE_TORQUE_MODE`：记录坡度（当前恒为 0）
- `0x43` → `TORQUE_DRIVE_MODE`：计算助力曲线并驱动电机
- `0x44` → `VELOCITY_MODE`：摆动相

### ✅ 安全功能
- 力保护：`|force| ≥ force_limit` 时电机立即停止
- 开机预紧：以 `preload_speed` 慢速收线，直到 `|force| ≥ preload_force`
- 编码器安全限位：超过 45° 触发归零

## 7. 关键参数与调参

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `control_mode` | 1 | 1=自适应扭矩曲线；2=定参数扭矩曲线 |
| `user_weight` | 60.0 | 体重 kg，影响峰值扭矩（`base = weight × 0.3`） |
| `force_limit` | 5.0 | 力限值（/Force 尺度），超限立即停电机 |
| `torque_per_force` | 6.0 | /Force 单位 → Nm 换算（台架杠杆比） |
| `motor_dir` | 1.0 | +1 收线拉紧，-1 放线 |
| `preload_speed` | 10.0 | 开机预紧爬速 deg/s |
| `preload_force` | 0.2 | 预紧目标力 |
| `preload_timeout` | 4.0 | 预紧超时 s |
| `max_speed` | 180.0 | 速度限幅 deg/s |

## 8. 已知问题

### 8.1 台架不松线（正常现象）
**原因：** 摆动相 `VELOCITY_MODE` 依赖编码器反馈 `theta_m > theta_d` 才发送反转速度。台架上编码器未与电机机械联动，因此不松线。上脚穿戴后应自动解决。

### 8.2 SIGINT 崩溃（非致命）
**现象：** 按 Ctrl+C 停止时，`serial_ForceSensor_node` / `serial_encoder_node` 偶发：
```
RCLError: failed to create guard condition: the given context is not valid
```
**原因：** ROS2 多节点同时 shutdown 的已知现象。
**影响：** 不影响运行期间功能；停止后可用 `scripts/stop_all.sh --auto` 清理残留。

### 8.3 编码器偶发跳变
**现象：** 编码器节点偶尔读到 39.99° 等异常值。
**原因：** Modbus 帧解析可能受干扰。
**建议：** 上线前验证 CRC 和超时处理是否足够 robust。

### 8.4 CAN 接收线程数据为 0
**现象：** `Output_TorqueValue`、`Output_VelocityValue` 当前为 0。
**原因：** 电机未配置 PDO 周期上报；控制逻辑目前不依赖这些值。
**如需启用：** 需在 `can_init()` 中配置 PDO 映射（COB-ID 0x1D3、0x3D3 等）。

### 8.5 IMU 坡度补偿未启用
代码已订阅 `/imu` 和 `/system_speed`，但 `initializeSlopeFile()` 被注释掉，因此 `Tor.TARGET_TORQUE_ASSIST` 恒为 0。需要坡度助力时取消注释并启用 fdilink_ahrs。
