## 2. STM32 脚底开关固件

### 最终源码：`/tmp/fw_v15.c`

| 引脚 | 功能 | 模式 |
|------|------|------|
| PA9 | USART1 TX | AF_PP 50MHz |
| PA10 | USART1 RX | 浮空输入 |
| PA12 | LED1 (后跟指示) | 推挽输出 50MHz，高电平亮 |
| PA15 | LED2 (前掌指示) | 推挽输出 50MHz，高电平亮 |
| PB5 | 后跟开关 | 浮空输入（需下拉电阻或改上拉） |
| PB6 | 前掌开关 | 浮空输入（需下拉电阻或改上拉） |
| PA13/PA14 | SWD 调试 | 保留 |

### 关键技术点：
- **时钟**：HSI 8MHz → PLL (HSI/2 ×12) = **48MHz**（不依赖外部晶振，稳定）
- **USART**：BRR=5000 → 48000000/5000 = **9600 bps**
- **PA15 JTAG 释放**：`AFIO_MAPR |= (2<<24)` → SWJ_CFG=010（只留 SWD）
- **向量表**：必须用链接脚本确保 `.vectors` 段在 0x08000000
- **GPIO_CRH 硬编码**：`0x344443B4`（PA9=B(USART), PA12=3(LED1), PA13/14=4(SWD), PA15=3(LED2)）

### LED 驱动：
- PA12/PA15 需要**跳线**连接 LED 电路（板上 LED 默认走 PA1/PA2）
- 跳线接好后：BSRR=亮，BRR=灭

### 编译烧录命令：
```bash
arm-none-eabi-gcc -mcpu=cortex-m3 -mthumb -O2 -nostartfiles -nostdlib \
    -T /tmp/link.ld -Wl,--build-id=none \
    /tmp/fw_v15.c -o /tmp/fw_v15.elf
arm-none-eabi-objcopy -O binary /tmp/fw_v15.elf /tmp/fw_v15.bin
sudo st-flash --hot-plug write /tmp/fw_v15.bin 0x08000000
# 拔插 ST-LINK USB 线复位！
```

### 开关接线待确认：
两种方案：
A) 开关接 3.3V，PB5/PB6 加 10kΩ 下拉到 GND（按下=高）
B) 开关接 GND，PB5/PB6 启用内部上拉（按下=低，需改固件）

## 4. 启动步骤

```bash

ls /dev/ttyUSB* /dev/ttyACM*

# T1: CAN 桥
sudo python3 /tmp/bridge.py

# T2: 开关 + 传感器

# T3: 助力控制器
```
