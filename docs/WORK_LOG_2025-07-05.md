## 2. 架构（ROS2 双进程 — 仍在用）

```
进程1(sudo): CAN_bridge ── TCP :9876 ── 进程2: ROS2控制器
       │                                        │
  python-can                              /target_torque
     电机                                 /motor_speed

进程3: 脚底开关 ROS2 节点 → /command_topic
进程4(C++): 传感器节点
```

**关键规则**：
- CAN 和 ROS2 绝不能在同一进程（fork/subprocess 破坏 DDS）

---

## 3. CAN 协议

- Node: 0x53, SDO TX: 0x653
- 电机使能: 0x6060=3 (PV模式), 0x6040: 6→7→0xF
- 速度指令: 0x60FF, uu/s = deg/s × 600
